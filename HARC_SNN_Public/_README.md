# Henderson Amateur Radio Club, Inc.
## Sunday Night Net Specifications

This directory contains information about the HARC Sunday Night Net (SNN) and how it is currently configured.

Should someone else take over the net administration, this process may differ substantially.

The DDL (Data Definition Language) directory contains the SQL definitions of the database including Tables and Views.

HARC_SNN_Specification (both .docx and .pdf) contain the descriptions of the overall business system.

Also contained in the HARC\_SNN\_PUBLIC Directory are the following:

|---------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|

| HARC\_Net\_Script\_2024034      | The script that was used during the March 31, 2024 net.                                                                                                                                                                                   |
